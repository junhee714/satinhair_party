# 지나의 파티 준비 (모바일 웹 게임)

정적 HTML/CSS/JS 프로젝트입니다. 빌드 없이 Vercel에 그대로 배포됩니다.

## 배포
1. 이 폴더를 GitHub에 올리고 Vercel에서 Import (Framework: Other, Build Command 비움), 또는
2. 터미널에서 `npx vercel --prod`

## 첫 화면 (인트로 모션 — mp4 대체)
- 영상 대신 캔버스로 그립니다. 파일은 `intro.js` + `assets/intro/*.webp` 입니다. 분홍 새틴 커튼(`curtain.webp`) 위에 닫힌 봉투가 왼쪽에서 기울어진 채 날아와 자리 잡고, 뚜껑이 정면(원근)에서 열리고, 편지지가 입장 조건 박스까지 올라옵니다 (약 5.1초).
- 편지지가 멈추면 '초대장 받기' 버튼(`assets/intro/btn-invite.webp`)이 같은 자리에서 활성화되고, 누르면 음악을 켜고 너드 지나 1 로 넘어갑니다 (`script.js` 의 `btnInvite`).
- 버튼 크기/위치는 `data.js` 의 `HOTSPOT_RECTS.introInvite` (버튼 138.2×35.6px + 둘레 5px 그림자 여백, 402×874 기준 0~1 비율) 입니다. 그림자는 버튼 이미지(`btn-invite.webp`)에 구워져 있어서 CSS 필터를 쓰지 않습니다(끊김 방지). 캔버스 안에서 편지지와 함께 올라오는 버튼 그림은 `intro.js` 의 `BW, BH, BTN_DY, BTN_IMG_*` 와 같은 값으로 맞춰져 있으니 위치를 바꾸면 둘 다 같이 바꾸세요. 편지지가 멈추는 프레임에 캔버스 버튼이 사라지고 진짜 버튼이 같은 자리에서 즉시 켜집니다.
- 모션·크기·타이밍은 `intro.js` 맨 위쪽 상수입니다: 시간(`FLY0/FLY`, `FLAP0/FLAP`, `LET0/LET`, `DROP0/DROP`, `TOTAL`), 봉투가 날아오는 시작 자세(`START_*`), 봉투가 자리 잡는/편지지가 나온 뒤의 위치(`HY0/HY1`), 편지지 크기·위치(`LW`, `LET_TOP`).
- 초대장 받기를 누르면 흰색 소프트 페이드(`D.softTransition`)로 너드 지나 1 에 들어갑니다. 페이드가 차오르는 동안 첫 장면 이미지를 미리 디코딩해(`prewarmStoryStart`) 장면이 바뀔 때 끊기지 않습니다.
- 뒤로 가기로 돌아오면 다시 재생하지 않고 편지지가 나온 마지막 장면 + 버튼으로 바로 갑니다. 처음부터 되돌리기(↺)와 다시하기는 처음부터 재생합니다.
- 예전 mp4 / 도와주기 버튼 / 선명도용 카드 오버레이는 모두 제거되었습니다 (`assets/media` 폴더 삭제).

## 새 장면 이미지를 추가할 때 (자막 타자기 자동 적용)
이미지에 박힌 자막은 그대로 두면 타자기 효과를 줄 수 없어서, 원본 이미지를 `tools/dialogue_pipeline.py` 로 처리합니다.

1. `tools/dialogue_specs.json` 에 새 이미지(`images`)와 자막 그룹(`groups`: 글자 영역 `region` + 대사 `lines`), ▶ 가 있으면 `arrows` 를 추가
2. `python3 tools/dialogue_pipeline.py tools/dialogue_specs.json` (numpy / opencv-python / pillow 필요, 원본 PNG 경로는 spec 의 `src`)
3. 결과: 자막 없는 `assets/scenes/<name>.webp`, 글자 레이어 `assets/text/text-<그룹>.png`, ▶ `assets/text/arrow-*.png`, 글자 위치 지도 `assets/text/dialogue-map.js`
4. `data.js` 의 `story.steps` 에 장면(kind / frames / text / arrow / next)을 추가하고, `story.images` 에 이미지 이름을 추가

말풍선 점무늬는 같은 이미지의 무늬를 복사해 복원하므로 글자를 지운 자리가 티 나지 않습니다.

## 선셋 허니 루트 작업 메모
선셋 허니 버전은 블라썸 루트와 **액션/순서는 그대로**, 이미지만 바뀝니다. (확정된 양식: 소프트 흰색 페이드 전환, 꽃잎류 FX는 처음부터 모션, 자막 빠르게 + 탭하면 즉시 완성, 오답 화면 흔들림+빠직, 8번 두 포즈 흔들림, 9번 머리 광택 1회 + ▶, 11번 ▶)
작업 순서: 새 이미지 → `tools/blossom_fx.py`(효과 분리) → `tools/dialogue_pipeline.py`(자막/▶ 분리) → `data.js` 의 `story.steps` 에 선셋 루트 단계 추가(블라썸 단계를 복사해 이미지/자막 id 만 교체), `routes` 에 fill/mute 패치 추가.

- 반짝임(11, 18) 직후 자막이 올라오는 속도: `data.js` 의 `story.afterFx` (크로스페이드 180ms, 타자 시작 대기 40ms). 효과 전체 길이는 `transform.totalMs`(2200).

## 배경음악
- 음량: 두 곡 모두 약 -13 LUFS 로 맞춤(첫 곡은 조용한 구간을 살짝 압축해 균일하게). 재생 볼륨은 `data.js` music.*.volume(현재 0.7). 음원은 워터마크 없는 m4a 버전으로 제작.
- 파일: `assets/audio/intro-bgm.mp3`(첫 화면), `assets/audio/story-bgm.mp3`(너드 지나 ~ 마지막 화면). 설정은 `data.js` 의 `music`(경로 / volume / fadeInMs / fadeOutMs / switchFadeMs).
- 첫 화면: 음악이 페이드 인(2초)으로 시작 → `초대장 받기`를 누르는 순간 첫 곡은 페이드 아웃(`crossFadeMs` 1.8초), 같은 순간 스토리 음악이 페이드 인(2.5초)으로 겹쳐 이어집니다(소리가 끊기지 않음). 페이드는 오디오 스레드에 예약되어 화면 전환 중 버벅여도 끊기지 않습니다.
- 선물받기/다시하기 화면(편지 화면)으로 넘어가면 스토리 음악이 4.5초에 걸쳐 페이드 아웃. 거기서 ← 로 돌아가면 다시 페이드 인.
- 맨 처음 화면으로 되돌아가면(←, ↺) 첫 화면 음악이 처음부터 다시 재생됩니다.
- 왼쪽 상단 ♪ 버튼: `음악 끄기`를 누르면 즉시 음악이 꺼지고(짧은 페이드), 다시 누르면 현재 화면에 맞는 음악이 페이드 인으로 켜집니다. 음소거 상태는 화면이 바뀌어도 유지됩니다.
- 자동 재생: 페이지가 열리면 바로 재생을 시도하고, 브라우저가 허용하면 첫 화면에서 클릭 없이 페이드 인으로 시작합니다. 브라우저 정책(Chrome/Safari 등)이 소리 있는 자동 재생을 막는 경우에는 첫 터치·클릭·키 입력·스크롤 순간에 시작합니다(첫 화면에는 ♪ 버튼이 없어 화면 아무 곳이나 처음 만지면 됨).
- `index.html` 을 파일로 직접 열었을 때(file://)는 브라우저가 WebAudio 소리를 무음 처리하므로 audio.volume 방식으로 자동 전환합니다. 배포(http/https)에서는 WebAudio(GainNode)로 페이드합니다(iOS 는 audio.volume 을 무시하기 때문).
- 탭이 가려지면(다른 앱/탭 전환) 음악이 일시정지되고 돌아오면 이어집니다. 

## 효과음 (`assets/audio/sfx/`, 설정은 `data.js` music.sfx)
효과음은 "버튼"을 누를 때만 납니다(자막 탭에는 없음). `♪ 음악 끄기` 상태에서는 효과음도 나지 않고, 켜는 순간 버튼음이 한 번 납니다. 볼륨은 sfx.*.volume.
- `click.mp3` : `초대장 받기`, 카드 버튼, ← ♪ ↺, 편지 화면 버튼(선물받기/다시하기). 자막 탭에는 없음.
- `magic.mp3` : (1) 너드 지나 → 블라썸1/선셋1 전환 (흰 페이드 시작 순간), (2) 11·18 변신 반짝임 — 반짝임이 실제로 시작되는 시점 + `transform.sfxDelayMs`(250ms) 뒤에 재생해 소리의 하이라이트가 빛이 가장 밝아지는 0.8초 지점에 오도록 맞춤.
- `comb.mp3` : 꼬리빗(오답) 선택 — 처음 선택할 때와 또 누를 때마다 (`cards.R.sfx: "comb"`).
- `glow.mp3` : 머리 반짝임(블라썸9/선셋9, "와! 고데기 돈모 브러쉬로…") 이 흐르기 시작하는 순간.
- `shine.mp3` : 커튼이 닫혔다 열릴 때. 커튼이 활짝 열리기 시작하는 순간(닫힘 260ms + 대기 200ms)에 소리의 하이라이트가 오도록 `curtain.sfxPeakMs` 만큼 앞당겨 재생 (커튼 열림 속도 약 1.05초에 맞춰 1.9초 길이로 늘려 만든 파일).
- `wind.mp3` : 편지 화면에서 초대장이 날아올 때(왼쪽→오른쪽으로 소리가 이동). 흰 페이드가 걷히며 봉투가 보이는 시점에 맞춰 `delayMs`(100ms) 뒤에 재생. 파일이 없어 새로 만든 소리.
